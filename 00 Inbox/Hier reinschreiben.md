# 📥 Inbox

Schreib deine Notizen einfach hier rein, als neue Notiz in diesem Ordner, so roh wie du willst. Stichpunkte, Tippfehler und fehlende Links sind egal.

Danach in Claude Code nur: **„Inbox verarbeiten“**

Claude macht daraus eine Session-Notiz, legt neue NPCs, Orte, Quests und Hinweise an, ergänzt die bestehenden, setzt alle Links und aktualisiert die [[Kampagnen-Übersicht]]. Verarbeitete Notizen werden aus der Inbox entfernt. Der Rohtext bleibt eingeklappt in der Session-Notiz erhalten.
