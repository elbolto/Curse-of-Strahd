# Das Durst-Haus

> [!info] Überblick
> Das Haus der [[Familie Durst]] in [[Barovia]]. Zwei Kinder baten uns, ihren kleinen Bruder daraus zu retten. Das „Tutorial“ der Kampagne fand hier statt. → [[Das Durst-Haus|Quest]]

## Räume
| Bereich | Was wir dort fanden |
|---|---|
| Überall | Gegenstände mit eingraviertem [[Windmühlen-Symbol]] |
| Obergeschoss, Geheimraum | Skelett mit dem [[Brief von Strahd an seinen Diener]] |
| Truhe | Eigentumsurkunden (Haus + Windmühle), [[Testament der Familie Durst]] |
| Wintergarten | Ein Walzer ist die ganze Zeit zu hören |
| Abstellkammer | Ein Besen greift Narri an |
| Schlafzimmer | Blutlache unter der Bettdecke, [[Brief von Klara]], Spiegel mit Geheimtreppe |
| Dachboden / Kinderzimmer | Geister und Skelette der beiden Kinder |
| Zimmer der Mutter | Schmuckschatulle mit [[Bernsteinsplitter]] und [[Notiz von Elisabeth an Drasha]] |
| Cembalo-Zimmer | Der Walzer: Geister aller Bewohner tanzen, zwei Figuren fallen aus dem Regal |
| Keller | 4 Grabkammern (eine fehlt), Raum mit Knochenhaufen |
| Unterer Keller | Säulensaal, 5 Schlafräume mit Feldbetten |
| Ganz hinten | Altar in 60 cm tiefem Wasser mit Tentakeln und einem Bündel auf dem Altar |
